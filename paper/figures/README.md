# Figures

Each PDF in this folder is produced by the namesake `.py` script with
frozen parameters. Re-running the script must reproduce the PDF
byte-equally (matplotlib `savefig(..., metadata={'CreationDate': None,
'ModDate': None})`).

Publication figures:

| File | Section | Description |
|---|---|---|
| `fig1_sudoku_projectors.pdf` | §3 | Sudoku grid with row-band / column-stack projector overlay. |
| `fig2_rank_distribution.pdf` | §4 | Rank distribution of $\{E_\gamma\}$ over $S_9$ on base1 (362858 vs 22). |
| `fig3_D6_cayley.pdf` | §5.2 | $D_6$ Cayley diagram inside $B_3 < S_7$. |
| `fig4_A8_saturation.pdf` | §7 | $\Lambda_M = \Lambda_{O_6} = A_8$ schematic. |
| `fig5_M19_coset_structure.pdf` | §8 | Bilateral coset structure of $\Gamma^*_{M_{19}}$. |
